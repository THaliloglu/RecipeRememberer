# Privacy

Recipe Rememberer stores recipe data locally on the device.

## What the app uses

- Camera access, only for recipe card capture.
- On-device storage, only for saved recipe titles, optional subtitles, save timestamps, source notes, recognized text, and saved recipe card photos.

## What the app does not do today

- No account system
- No cloud sync
- No analytics
- No advertising
- No third-party SDK tracking

## Data handling

- Recognized recipe text is used to compare against the local library and help the user save recipes.
- Saved recipes remain on-device unless a future version adds optional sync.

Review and update this policy again before release if the app later adds analytics, cloud sync, or external APIs.
