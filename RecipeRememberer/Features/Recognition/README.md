# Recognition

## Overview

The two-photo recipe scanner, on-device text analysis, and pending-save review UI. The scanner captures front and back images, analyzes them, and passes the reviewed result to `AppModel`; the app layer decides how to save or stage the payload.

## Interface

The following types are module-internal; this directory declares no `public` API.

- [ScannerDashboardView.swift](./ScannerDashboardView.swift): `ScannerDashboardView` composes the scanner entry section and pending review card. [ScannerDashboardView.swift:ScannerDashboardView]
- [ScanRecipeTitleSection.swift](./ScanRecipeTitleSection.swift): `ScanRecipeTitleSection` offers `AppModel.SaveMode` selection and full-screen scanner presentation. [ScanRecipeTitleSection.swift:ScanRecipeTitleSection]
- [LiveTitleScannerView.swift](./LiveTitleScannerView.swift): `LiveTitleScannerView` manages permission, capture, per-side orientation, analysis, retakes, and committing the payload. Its scanner state and supporting controls are private. [LiveTitleScannerView.swift:LiveTitleScannerView]
- [PendingSaveCard.swift](./PendingSaveCard.swift): `PendingSaveCard` presents draft title/subtitle editing and captured-photo previews with duplicate feedback. [PendingSaveCard.swift:PendingSaveCard]
- [RecipeCardCameraView.swift](./RecipeCardCameraView.swift): `RecipeCardCameraView` bridges capture trigger, zoom, guide rectangle, and data/error callbacks to the `@MainActor` `RecipeCardCameraViewController`. `RecipePhotoGuideCropper.crop(photoData:normalizedRect:)` returns optional cropped JPEG bytes. [RecipeCardCameraView.swift:RecipeCardCameraView] [RecipeCardCameraView.swift:RecipeCardCameraViewController] [RecipeCardCameraView.swift:RecipePhotoGuideCropper]
- [RecipePhotoAnalyzer.swift](./RecipePhotoAnalyzer.swift): `RecipePhotoAnalyzer.analyze(frontImageData:backImageData:)` is async throwing and returns the `Equatable`, `Sendable` `RecipePhotoAnalysis` containing title, subtitle, both OCR texts, and summary. `RecipePhotoAnalyzerError.noRecipeTextDetected` is the empty-title error. [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzer] [RecipePhotoAnalyzer.swift:RecipePhotoAnalysis] [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzerError]

## Invariants

- Analysis starts only with both images, and commit requires both images plus an analysis result. Capturing the front advances to back unless back bytes already exist; retaking one side retains the other. [LiveTitleScannerView.swift:analyzeCapturedPhotos] [LiveTitleScannerView.swift:commitDetectedRecipe] [LiveTitleScannerView.swift:handleCapturedPhotoData] [LiveTitleScannerView.swift:retakeFrontPhoto] [LiveTitleScannerView.swift:retakeBackPhoto]
- Analysis completion presents a commit action in either save mode. Choosing that action passes the payload to `AppModel.scanCapturedRecipe`; OCR completion alone does not call it. [LiveTitleScannerView.swift:ScannerBottomPanel] [LiveTitleScannerView.swift:commitDetectedRecipe]
- Pending review is shown only for a draft with a capture payload. Save is disabled for a whitespace-only title or a detected duplicate; duplicate checks run on appearance and title/subtitle changes. [PendingSaveCard.swift:PendingSaveCard] [PendingSaveCard.swift:PendingRecipeDraftEditor] [PendingSaveCard.swift:PendingRecipeDraftEditor.refreshDuplicateRecipe()]
- Authorization maps undetermined to permission request, denied/restricted to denial, and authorized to ready. `shouldUseMockScanner` (`-uiTestMockScanner`) takes precedence by returning the ready state and replacing the preview; it does not generate images or analysis on its own. Otherwise a stored fatal error precedes authorization. Permission/analysis tasks check cancellation before applying asynchronous results. [LiveTitleScannerView.swift:scannerState] [LiveTitleScannerView.swift:cameraSurface(guideRect:)] [LiveTitleScannerView.swift:requestCameraAccess] [LiveTitleScannerView.swift:analyzeCapturedPhotos]
- A changed capture trigger requests a photo. Unconfigured capture reports an error, concurrent in-flight capture returns, and processing completion clears the in-flight flag. Crop failure delivers the original bytes. [RecipeCardCameraView.swift:RecipeCardCameraView.updateUIViewController(_:context:)] [RecipeCardCameraView.swift:RecipeCardCameraViewController.capturePhoto()] [RecipeCardCameraView.swift:RecipeCardCameraViewController.photoOutput(_:didFinishProcessingPhoto:error:)]
- Camera zoom clamps the requested value between 1 and the lesser of hardware maximum and 5; the UI slider offers 1 through 4 in 0.25 steps. [RecipeCardCameraView.swift:RecipeCardCameraViewController.setZoomFactor(_:)] [LiveTitleScannerView.swift:CameraZoomControl]
- Cropping bounds the standardized normalized rectangle to the unit square, transforms orientation through `RecipePhotoCropGeometry`, bounds integral pixel coordinates to the image, and encodes JPEG at quality 0.92. Invalid/empty crops return `nil`. [RecipeCardCameraView.swift:RecipePhotoGuideCropper.crop(photoData:normalizedRect:)]
- Front/back recognition uses `async let`. OCR is accurate, language-corrected, configured for `de-DE` and `en-US`, and uses minimum text height 0.02; full text is ordered by top-origin Y then X. [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzer.analyze(frontImageData:backImageData:)] [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzer.recognizeText(in:)]
- Title precedence is parsed front title, prominent front title, fallback front title, fallback back title, then empty string. A parsed title takes precedence and has no equivalent six-character/two-word minimum; a one-word title such as `Soup` is possible when the parser accepts it. The analyzer still throws `noRecipeTextDetected` for an empty trimmed final title. [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzer.analyze(frontImageData:backImageData:)] Core parser: `/Packages/RecipeRemembererCore/Sources/RecipeRemembererCore/RecipeCardTextParser.swift`, `RecipeCardTextParser.parse(from:preferredTitle:)`.
- Only analyzer prominent/fallback candidates selected through `isLikelyFrontTitleLine` require at least six characters and two words and reject configured blocked terms. Candidates are scored by geometry, word count, and keywords. [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzer.isLikelyFrontTitleLine(_:)] [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzer.titleCandidateScore(for:text:)]
- Subtitle uses the parsed front subtitle, then the front fallback if the parsed result is absent. An empty parsed subtitle is non-nil and does not trigger fallback. Returned title/subtitle are trimmed. [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzer.analyze(frontImageData:backImageData:)]
- The analysis summary starts with the detected title, includes a nonempty subtitle, adds the first matching front-OCR cooking-time range and calorie text when present, and always includes front/back line counts. A back-OCR note is added only when back text is nonempty. Time matches use one- or two-digit endpoints separated by a hyphen or en dash and followed by `Min`, `Minute`, or `Minutes`; calorie matches use two to four digits followed by `kcal`. These patterns are case-sensitive as written. See [analyzer source](./RecipePhotoAnalyzer.swift): `RecipePhotoAnalyzer.analysisSummary` and `firstMatch(in:for:)`.
- The summary currently describes the title as coming from the front photo even when back-photo fallback supplied it; that wording is not a provenance guarantee. `AppModel.saveDraft(_:using:)` copies the generated summary into the record without recomputing it (repository path `/RecipeRememberer/App/AppModel.swift`). [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzer.analysisSummary]

## Side Effects

- Entry controls mutate `AppModel.saveMode` and present the scanner. Permission requests call `AVCaptureDevice.requestAccess`; Settings opens the app settings URL. Disappearance cancels and clears permission and analysis tasks. [ScanRecipeTitleSection.swift:body] [LiveTitleScannerView.swift:requestCameraAccess] [LiveTitleScannerView.swift:openAppSettings] [LiveTitleScannerView.swift:body]
- The camera controller configures back-camera input/output and preview, starts/stops its capture session on appearance/disappearance, and changes supported focus, exposure, and zoom settings. It sends captured bytes or errors through callbacks. [RecipeCardCameraView.swift:RecipeCardCameraViewController] [RecipeCardCameraView.swift:RecipeCardCameraViewController.focusCamera(at:)] [RecipeCardCameraView.swift:RecipeCardCameraViewController.setZoomFactor(_:)]
- Analysis normally performs Vision OCR. Capture/analysis/retake/reset actions mutate local scanner state. `shouldUseMockScannerCapture` (`-uiTestMockScannerCapture`) instead supplies generated photos in `captureCurrentSide` and substitutes `UITestRecipeSeeder`'s fixed analysis result in `analyzeCapturedPhotos`. This flag does not replace the preview or bypass camera authorization; neither mock flag enables the other. Use both for the complete [simulator setup](../../../README.md#running-the-app). Launch flags and seeder: `/RecipeRememberer/App/UITestLaunchConfiguration.swift`, `UITestLaunchConfiguration` and `UITestRecipeSeeder`. [RecipePhotoAnalyzer.swift:RecipePhotoAnalyzer.recognizeText(in:)] [LiveTitleScannerView.swift:captureCurrentSide] [LiveTitleScannerView.swift:analyzeCapturedPhotos] [LiveTitleScannerView.swift:resetCapturedPhotos]
- Commit constructs `RecipeCapturePayload` with source `two-photo scanner`, images, and analysis fields, calls `AppModel.scanCapturedRecipe(_:using:)`, then dismisses. Pending Save calls `updatePendingDraft` then `confirmPendingSave(using:)`; Not Now calls `dismissPendingSave`. [LiveTitleScannerView.swift:commitDetectedRecipe] [PendingSaveCard.swift:PendingSaveCard]

## Verification

From the repository root, run the app scheme's configured unit and UI tests:

```sh
xcodebuild -project RecipeRememberer.xcodeproj -scheme RecipeRememberer -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test
```

The repository README documents this command. The shared scheme includes `RecipeRemembererTests` and `RecipeRemembererUITests`; real capture requires a device, while the feature explicitly supports mock scanner launch configuration.
