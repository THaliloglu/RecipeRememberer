# Support

Recipe Rememberer is currently a small independent project.

## Getting Help

- Open an issue in the GitHub repository for bugs, scanner problems, or feature requests.
- Include your device model, iOS version, and a short description of what happened.
- If the issue involves title recognition, include the printed recipe title text that failed if you can share it.

## Known Limitations

- Live title scanning requires a supported iPhone or iPad camera.
- Simulator is useful for UI testing, but manual title entry is the main fallback there.
- Recipes are stored locally on-device. The app does not currently sync across devices.
